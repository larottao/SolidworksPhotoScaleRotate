No more fighting with the Solidworks Sketch Picture dialog, and its clumsy rotation / scaling system

1. Load the image.

2. Use the orange ruler (optional) to find the right angles of your crooked object (example: a PCB).

3. Mark the X and Y lines, enter their distances in mm.

4. Image will be automatically scaled and rotated properly (X axis aligned with the horizon).

5. Import into Solidworks and enjoy.

For best results, take your PCB pictures from the longest distance possible (a.k.a. poor's man telecentric lens).
